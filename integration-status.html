Página interna de desenvolvimento (não linkada no menu, noindex). Nenhum dado de conexão é buscado no backend até o segredo administrativo ser validado abaixo — antes disso a página não faz nenhuma chamada de status.

Não é um painel público. Esta página é uma ferramenta de desenvolvimento/configuração, não uma tela protegida por login. O segredo administrativo é validado pelo backend a cada ação, mas o arquivo HTML/JS em si é público como qualquer outro arquivo estático do site. Não publique este caminho abertamente em produção: mantenha-o fora do deploy público, restrinja por Basic Auth / allowlist de IP na hospedagem, ou sirva-o só num ambiente interno/staging. Ver docs/BLING_SETUP_MANUAL.md.
